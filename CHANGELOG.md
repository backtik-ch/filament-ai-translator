# Changelog

All notable changes to `filament-translatable` will be documented in this file.

## 0.1.0 - 2025-05-22

### Added

- **TranslatableInput** — Form field with modal mode (default) and inline mode
- **TranslatableEntry** — Infolist entry with inline (expandable) and modal display modes
- **AI Translation** — Generate all translations in a single API call via laravel/ai
- **Line clamp** — `->lineClamp()` support on TranslatableEntry
- **Panel plugin** — Configure languages, source locale, AI provider/model per-panel
- **Filament 4 & 5** compatibility
